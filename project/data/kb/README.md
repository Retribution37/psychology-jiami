# 本地心理学知识库与 RAG

这个目录服务于"云端报告专业化"：本地先把档案脱敏，再按脱敏文本检索公开专业资料，把编号后的参考资料随提示词发给云端，要求模型只依据资料编号引用。知识库全部在本机，不新增在线服务，也不上传任何真实身份。

## 1. 来源怎么选

评估维度：

1. **发布机构与评审**：国家级机构、专业学会、同行评审教材优先；自媒体、商业软文、无法追溯出处的"心理学小知识"一律不用。
2. **证据基础与更新状态**：指南优先于教材，教材优先于科普；优先现行版本。
3. **适用场景**：区分临床指南、行政规范、教育政策、开放教材，不把一般心理教育写成诊断结论。
4. **许可与可引用性**：政府公开文件、OGL、CC BY 可直接引用；受版权保护的专著只做书目推荐，不复制正文入库。
5. **外部评价**：机构指南看行业采用情况；教材看豆瓣等读者评价，仅作辅助，不替代专业判断。

质量分级：**A** 可直接支撑专业原则；**B** 可用于背景与心理教育，不替代临床指南。

## 2. 教材评价与版权处理

| 教材 | 外部评价 | 处理 |
|---|---|---|
| 认知行为疗法：基础与应用（第三版） | 豆瓣不同版次约 8.9-9.2，读者普遍评价为 CBT 入门与临床实践首选 | 不复制正文；只把 CBT 通用概念转述为知识卡，并在书目中推荐原书 |
| 心理咨询与治疗的理论及实践（第10版） | 长期作为咨询导论教材，评价集中在体系完整、案例贯穿 | 同上；伦理与转介卡片主要依据学会守则，不依赖该书原文 |
| 变态心理学（第6版） | 豆瓣 9.4，读者评价科学严谨、案例丰富 | 同上；症状识别卡片以 WHO/NICE 指南为准 |

**为什么不做整书入库**：这些书受版权保护，把正文切块入库并随提示词发送会给项目带来许可风险；课程演示也不需要整书语料。采取"公开指南转述入库 + 教材只做书目推荐"的方式，既能提升报告的专业性，也能说明来源边界。

## 3. 知识卡

`knowledge.jsonl` 共 60 张卡，每行一个 JSON：

```json
{"id":"risk-01","topic":"风险评估","title":"自杀风险应直接询问","tags":["自杀","自杀观念","风险","询问"],"content":"...","source":"nice-ng222","source_detail":"1.2.8 风险评估与管理"}
```

- 9 个主题：风险评估 11、抑郁 9、焦虑 7、睡眠 6、家庭与关系 7、CBT与咨询技术 6、伦理与法律 7、报告写作 3、大学生心理 4。
- 卡片正文是**转述摘要**，不是指南原文；`source_detail` 标注对应章节或条目，便于人工复核。
- 不收录真实个案、真实姓名、联系方式或任何可识别信息。
- 新增卡片时必须同时提供 `source`（必须在 `sources.json` 中存在）和 `source_detail`；`python -c` 的完整性检查见项目自检。

## 4. 检索设计

`app/kb.py` 实现零依赖中文 BM25：

1. **字段加权**：标题 ×3、标签 ×2、主题 ×2、正文 ×1。
2. **中文切词**：汉字单字 + 双字组合；去掉高频功能字；占位符先剔除，避免"人物A"干扰检索。
3. **同义词扩展**：睡不着→失眠、不想活→自杀、嘲笑/孤立→欺凌、分手→失恋等，弥补词面不匹配。
4. **多样性**：同一主题最多 2 张，主议题最多 3 张；默认返回 6 张。
5. **安全兜底**：文本出现自杀/自伤等线索时，确保至少有一张风险评估卡进入参考资料。
6. **阈值**：最高分低于 1.5 或低于最高分 30% 的卡不返回，减少弱相关噪声。
7. **引用清理**：报告生成后删掉超出参考资料编号范围的 `[n]`，避免模型编造来源。

没有使用向量检索：60 张卡的规模下 BM25 足够，且不需要额外模型、GPU 或联网，演示可离线复现；代价是对同义改写不如语义检索稳健，后续可换成 embedding + 混合检索。

## 5. 隐私边界

- 检索查询 = 脱敏后的档案文本 + 受控关系词（如"室友""母亲"），不包含真实姓名、地址、账号或 `note`。
- 知识卡与来源元数据本身不含个人信息；随提示词发往云端的是公开资料的转述内容。
- 前端只拿到参考元数据（标题、主题、来源、年份、URL），拿不到知识卡正文之外的任何本地数据。
- 参考资料块带有"不得编造来源、不得把一般原则当个案事实"的约束。

## 7. 局限

1. 60 张卡只覆盖常见主题，不能替代完整指南；复杂共病、药物与法律个案需查原文。
2. BM25 依赖词面，隐晦表达或长段改写可能漏检。
3. 部分政策（如校园欺凌方案）面向中小学，知识卡已注明适用范围；用于高校场景时需结合《高等学校学生心理健康教育指导纲要》。
4. 指南会更新，`sources.json` 的年份与链接需定期复核。
5. RAG 只能提升"原则与建议"的专业性，不能保证报告对个案事实的判断正确；报告仍由有资质人员复核。
